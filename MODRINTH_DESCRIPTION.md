# Terminus — русская локализация

Неофициальный ресурспак с русским переводом и синтезированной озвучкой для сюжетного хоррор-мода **Terminus**. Он сохраняет смысл и тревожный тон оригинальных реплик, включая намеренные повторы, помехи и скрытые фрагменты текста.

Это дополнение, а не перезалив оригинального мода. Для игры отдельно установите [Terminus от DregIr / Danila Podpivas](https://www.curseforge.com/minecraft/mc-mods/terminus-horror).

## Что входит в пакет

- 104 строки стандартной локализации;
- 56 речевых файлов с синтезированной русской озвучкой;
- переведённые названия биомов, блоков, существ и точек интереса, а также субтитры, команды и статусы из языкового файла.

Музыка, фоновые звуки, механики и игровые данные не менялись.

## Совместимость

- Minecraft 1.20.1
- Forge 47+
- GeckoLib 4.4+
- Terminus 1.0.0

Работа на других версиях не проверялась.

Структура и целостность архивов проверены, но эта сборка ещё не запускалась в клиенте Minecraft.

## Установка

1. Установите Forge, GeckoLib и оригинальный Terminus.
2. Переместите ZIP-файл локализации в папку `resourcepacks`. Распаковывать его не нужно.
3. Включите пакет в настройках Minecraft и поставьте его выше других пакетов, меняющих Terminus.
4. Выберите русский язык.

## Ограничение ресурспака

В Terminus есть 117 английских надписей, встроенных непосредственно в Java-код. Пакет ресурсов не может их заменить, поэтому часть сюжетных сообщений, статусов и настроек останется на английском. JAR с полным переводом через эту страницу не распространяется.

## Использование генеративных инструментов

Перевод и текст этой страницы подготовлены с помощью генеративного ИИ. После перевода проверены смысл, единообразие терминов, плейсхолдеры и структура архивов. Все русские голосовые реплики синтезированы.

## Предупреждение о содержании

В моде есть пугающие образы, тревожные звуки, громкие предупреждения и визуальные помехи.

## Terminus Russian Localization

An unofficial Russian translation and synthesized voiceover resource pack for the story-driven horror mod **Terminus**. The original mod is required.

The pack translates 104 standard language entries and replaces 56 spoken audio tracks with synthesized Russian speech. Music, ambient sounds, mechanics, and gameplay data are unchanged.

It supports Minecraft 1.20.1, Forge 47+, GeckoLib 4.4+, and Terminus 1.0.0. Other versions have not been tested. The archives were checked for structure and integrity, but this release has not yet been launched in the Minecraft client.

The original mod contains 117 English messages embedded directly in Java code. Resource packs cannot replace those messages, so some story, status, and configuration text remains in English. A modified full JAR is not distributed on this page.

The translation and project-page text were produced with generative-AI assistance. Russian voice lines are synthesized. This project contains AI-generated content and derivative content.

Original mod: [Terminus by DregIr / Danila Podpivas](https://www.curseforge.com/minecraft/mc-mods/terminus-horror).
